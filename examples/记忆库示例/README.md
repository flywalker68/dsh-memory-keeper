# 示例记忆库

一个最小的、能直接用的记忆库骨架。四个文件，对应四种最常见的用法。

## 怎么用

```bash
# 复制到你的记忆库目录（默认 ~/.dsh/memory）
cp -r examples/记忆库示例/* ~/.dsh/memory/
```

然后**改成你自己的事**——里面的「小助」「用户」都是虚构的，日期和事件也是。

## 四个文件各自管什么

| 文件 | 用途 | 关键格式 |
|---|---|---|
| `00-索引.md` | 目录 + 变更日志 | 随便写，插件不读它 |
| `05-自我.md` | 我是谁 / 关系片段 / 我在意的事 | `- **YYYY-MM-DD** · 具体发生了什么` |
| `07-日程.md` | 日历 | 表格，第一列 `YYYY-MM-DD` |
| `12-进行中.md` | 手头的事 | `- **YYYY-MM-DD** · 一句话` |

## 别只写结论

关系片段最容易犯的错是写成结论：

```markdown
- 用户很信任我          ← 没用，检索时搜不到任何具体东西
```

写成具体的事：

```markdown
- **2026-11-03** · 用户说「你不用每次都问我」  ← 以后问「什么时候开始放手的」能翻出来
```

## 不用四个都建

- 只写一个 `记忆.md` 也行——插件不挑文件名
- 但**分文件**更清楚，也不容易一个文件长到几百 KB
