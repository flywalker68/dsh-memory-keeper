# 记忆文件格式说明

插件是**按行解析** md 的，所以格式不用严格，但有几处是「认得出 / 认不出」的区别。这份说明用最小例子讲清楚。

## 1. 普通记忆条目（最常用）

```markdown
- 用户喜欢喝无糖美式，下午三点后不碰咖啡
- 猫叫豆包，橘色，怕生
```

- 一行一条，`-` 开头
- **太短的行（< 6 字）会被跳过**，标题行（`#`）、引用行（`>`）、分隔线也不进索引
- 一行最多读前 300 字

## 2. 带日期的条目（时间检索要用）

```markdown
- **2026-11-04** · 用户说这周五要交材料
- **2026-11-03 · 他说「别急」**：三个字的安抚，不是敷衍
```

两种写法都认：

- `- **日期** · 正文`
- `- **日期 · 标题**：正文`

日期必须写在**行首**、`**` 里面。写在正文中间的不算（那是引用，不是这条的时间）。

> 查询里出现「三天前 / 上周 / 一个月前 / 10月31号」时，这些日期的条目会被加分。

## 3. 关系片段 / 印象（`05-自我.md` 用）

```markdown
- **2026-10-17** · 用户给助手起了名字。那天他说「以后你就叫小助手」
- **2026-10-24** · 他说「别怕，我在」
```

- 格式：`- **YYYY-MM-DD** · 正文`
- 可选后缀：`〔重要度 80〕`、`〔小助手〕`（标记来源）
- `memory_check` 会数你有多少条、最近一条是哪天

## 4. 日程表（`07-日程.md` 用）

```markdown
| 日期 | 时间 | 事项 | 状态 |
|---|---|---|---|
| 2026-11-06 | 09:00 | 交材料 | 待办 |
| 2026-11-04 | 下午 | 规则体检 | 已完成 |
```

- 表格行，第一列是 `YYYY-MM-DD`
- 状态写「已完成」的行会从「今天/明天」提示里排除
- 读成：今天几件、明天几件、这周几件、更远几件

## 5. 日记（`日记/YYYY-MM/YYYY-MM-DD.md`）

```markdown
# 2026-11-04

## 小助手

今天先是……

〔钩子：某个细节、某句话、某个瞬间〕
```

- 文件名必须是 `YYYY-MM-DD.md`，放在 `日记/YYYY-MM/` 下
- **`〔钩子：…〕` 那行会被加权**——以后检索更容易命中
- `## 小助手` 这类二级标题下的内容正常索引

## 6. 对话记录（自动生成，不用手写）

`<workspace>/对话记录/YYYY-MM/YYYY-MM-DD.md`，由 DSH 导出工具生成。`chat_search` 就是读它来「翻原话」的。

## 7. 索引与向量（自动生成）

```
<workspace>/.tools/memory-index.json    切好的块 + 词频
<workspace>/.tools/memory-vectors.json  每块的向量（base64）
```

**不用管这两个文件**：源文件指纹一变，下次检索会自动重建。

## 一个最小的可用记忆库

```
~/.dsh/memory/
├── 00-索引.md        # 可以有也可以没有，先放着当目录
├── 05-自我.md        # 人设 + 关系片段
├── 07-日程.md        # 表格
└── 12-进行中.md      # 手头在做的事
```

写到上面这些文件里，启动 DSH 就能被 `memory_search` 搜到。

## 不想写这么多？

**只写一个 `.md` 也行**——把 `memoryDir` 指向任何目录，里面丢一个 `记忆.md`，照第 1 条的格式写就行。插件不挑文件名。
